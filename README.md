## 🎮 Quick Start

### Prerequisites
- Python 3.10+
- `pip` / `make`

```bash
# Clone the repository
git clone git@github.com:skrehanahamed/Apex_Overdrive.git
cd Apex_Overdrive

# Run the game (automatically sets up virtual environment and installs dependencies)
make run

# Watch the autopilot demo
make bot

# Rebuild assets/ from sheets/ if needed
make assets
```

Or run manually:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## 🏁 Gameplay & Features

- **Police Pursuits & Heat Meter**: You start with an open highway. Soon the sirens blaze and police join the chase. Keep the pursuit bar away from **BUSTED**. Escape the pursuit to raise your Heat level (faster cruisers, heavier traffic, double roadblocks).
- **Near Misses & Nitro Boost**: Thread the needle through congested traffic to earn Near Miss combos and replenish nitro. Grab glowing blue canisters on the track for instant refills.
- **Working Rear-View Mirror**: Real-time rearview mirror rendering police cruisers closing in behind you.
- **Procedural Synthwave Audio**: Zero external audio files — layered engine audio, gear shifts, tyre screeches, turbo whines, police sirens, and procedural synthwave soundtrack synthesized on the fly via NumPy.
- **Dynamic Themes & Scenery**: Multiple visual biomes (Sunset, Midnight, Dawn, Vaporwave) with custom roadside dressings, billboards, and horizon backdrops.
- **CRT Simulation**: Built-in retro arcade CRT scanline post-processing filter.

## 📁 Repository Layout

```
main.py            Entry point (--bot, --shot out.png, --title)
apex/
  world.py         Physics, traffic AI, pursuit logic, pickups
  render.py        Road projection, backdrops, sprites, HUD, overlays
  track.py         Track geometry, themes, roadside dressing
  assets.py        Sprite loading & world coordinate scaling
  audio.py         NumPy-synthesised engine, effects, and soundtrack
  font.py          UI font rendering
  game.py          Main loop, state management, windowing
sheets/            Raw source sprite sheets and panoramic backdrops
assets/            Trimmed transparent sprites (generated by tools/build_assets.py)
brand/             Logos and preview screenshots
tools/
  build_assets.py  Sprite sheet extraction tool
ApexOverdrive.spec PyInstaller multiplatform build specification
.github/workflows/
  ci.yml           Automated testing & headless smoke tests
  release.yml      Automated multiplatform binary builds (Win/Linux/Mac)
```

## 🚀 Releases & Standalone Builds

Pre-built standalone executables for **Windows**, **Linux**, and **macOS** are automatically generated and attached to each release on the [Releases](https://github.com/skrehanahamed/Apex_Overdrive/releases) page.

To build a standalone executable locally:
```bash
pip install pyinstaller
pyinstaller ApexOverdrive.spec --noconfirm
# The compiled bundle will be in dist/ApexOverdrive/
```
